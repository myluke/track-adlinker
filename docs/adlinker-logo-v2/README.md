# AdLinker Logo · 第二版

保留深墨绿与青绿色的双链接；将绿色链环末端接成向右上方的箭头，表达转化增长。字母 i 的点使用同色方形，呼应数据追踪。字重从 720 微调为 700，并调整图文间距。辅助标语为 **Link. Track. Grow.**（连接、追踪、增长）。

## 使用

主色为深墨绿 `#122C2A`、青绿 `#00AA86`；浅底辅助色 `#E6F7F2`。深色背景使用白色字标与 `#38D9B0` 强调色。

横向 Logo 建议不小于 150 像素宽；更小的位置使用独立图标。保持宽高比，并在四周留出至少图标短边 1/4 的空间。域名与辅助标语不并入主标志。

字标基于 Manrope 700 字重，已转为路径。SVG 自包含，无需外部字体或图片；字体许可见 `FONT-LICENSE.txt`。制作方式为直接绘制 SVG、渲染 PNG，未使用 AI 出图 API。

第一版保留在相邻的 `adlinker-logo/` 目录。本次仅交付独立设计素材。
